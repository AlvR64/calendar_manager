# Calendar Manager Frontend 2

Independent redesign candidate for Calendar Manager. The current production candidate remains in `../frontend/`.

## Commands

- `npm install`
- `npm run dev`
- `npm run typecheck`
- `npm run lint`
- `npm run build`
- `npm test -- --run`

The development server runs at `http://localhost:5174`. Set `VITE_API_BASE_URL` in `.env.local` when the API is not running at the default URL.

See `../docs/task-specs-frontend2/` for redesign specs. This application must not import code from `../frontend/`.
